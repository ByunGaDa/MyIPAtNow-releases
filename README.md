# MyIP@Now — Windows 설치 파일

MyIP@Now PC 앱의 Windows 설치 파일(Setup.exe)을 내려받는 곳입니다. 소스 코드는 여기 없습니다.

- 최신 설치 파일: [MyIPAtNow-Setup.exe](https://github.com/ByunGaDa/MyIPAtNow-releases/releases/latest/download/MyIPAtNow-Setup.exe)
- 모든 버전: [Releases](https://github.com/ByunGaDa/MyIPAtNow-releases/releases)

설치 파일은 아직 코드 서명이 없습니다. "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.
각 릴리스 본문의 SHA-256 값으로 받은 파일을 확인할 수 있습니다. 설치된 앱은 새 버전이 나오면 알려 줍니다.
